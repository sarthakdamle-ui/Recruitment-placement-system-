# Static UI prototype

These standalone HTML/CSS mockups are for visual demonstration and follow the project abstract. They use sample data, are not connected to Python/MySQL, and their forms are intentionally non-functional.

## View

Open `index.html` in a browser to see the login mockup. After that, use the sidebar to navigate through the dashboard, candidates, jobs, applications, interviews, offers, placements, and reports.

The connected Flask application is a separate optional extension in the parent project.
